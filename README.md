# SolUP — кейсы, апгрейд и краш с Telegram-подарками

Telegram-бот + Mini App в стиле RubUP.

- **Пополнение:** Telegram Stars, TON/USDT через @CryptoBot, Telegram-подарки (отправляются на аккаунт-релеер).
- **Игры:** кейсы (x1–x5), апгрейд предметов, краш в реальном времени.
- **Вывод:** выигранные предметы выводятся настоящими коллекционными подарками с релеера.
- **Также:** реферальная программа, ежедневный бонус, живая лента выигрышей, provably fair, админка в боте.

## Структура

```
backend/app/
  main.py       FastAPI + запуск бота, краша и опроса CryptoPay, раздаёт собранную Mini App
  bot.py        aiogram: /start, Stars, подарки через Business-релеер, админ-команды
  api.py        REST + WebSocket для Mini App
  games.py      кейсы, апгрейд, продажа, бонус, смена сида
  crash.py      движок краш-игры
  gifts.py      приём и вывод подарков
  cryptopay.py  TON/USDT через Crypto Pay API
  wallet.py     атомарные операции с балансом, рефералка
  fair.py       provably fair
  catalog.py    стартовые предметы и кейсы (RTP подбирается автоматически)
webapp/         React + Vite Mini App
```

## Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -r backend\requirements.txt
cd webapp && npm install && npm run build && cd ..
copy backend\.env.example backend\.env   # и заполнить
cd backend && ..\.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

Mini App нужен публичный HTTPS-адрес. Для теста подойдёт `cloudflared tunnel --url http://localhost:8000`:
полученный адрес укажите в `WEBAPP_URL` и в @BotFather (Bot Settings → Configure Mini App).

Для локальной разработки без Telegram: `DEV_AUTH=true` в `.env`, затем откройте `http://localhost:8000/?dev=123`.
**В продакшене `DEV_AUTH` обязательно должен быть `false`.**

## Запуск в Docker

```bash
cp backend/.env.example backend/.env   # и заполнить
docker compose up -d --build
```

Mini App и API будут на порту 8000. База SQLite лежит в томе `solup-data` и переживает пересборки.
Для HTTPS поставьте перед контейнером reverse-proxy (Caddy, nginx) или туннель cloudflared.

## Настройка подарков (релеер)

1. Отдельный аккаунт с Telegram Premium: Настройки → Telegram для бизнеса → Чат-боты → добавить вашего бота.
   Выдайте права на просмотр и передачу подарков и звёзд.
2. В `.env` укажите `RELAYER_USER_ID` и `RELAYER_USERNAME`. Бот сам сохранит подключение и напишет админам.
3. Пользователь отправляет подарок релееру, и бот зачисляет его стоимость:
   - коллекционный подарок — по цене из таблицы предметов;
   - обычный — по цене конвертации в звёзды.
4. Вывод: бот находит на релеере подарок нужной коллекции и передаёт его игроку.
   - Если подарка нет в наличии, предмет возвращается в инвентарь.
   - Плата за передачу списывается со звёзд релеера.
   - Пока `WITHDRAW_AUTO=false`, каждую заявку подтверждает админ кнопкой в боте.

## Админ-команды

| Команда | Что делает |
|---|---|
| `/stats` | пополнения, балансы, инвентари, профит |
| `/addbalance <id> <монеты>` | начислить или списать баланс |
| `/setprice <коллекция> \| <цена>` | цена коллекции подарка (влияет на RTP кейсов) |
| `/withdrawals` | заявки на вывод с кнопками |
| `/stock` | какие подарки есть на релеере и сколько на нём звёзд |
| `/user <id>` | баланс и последние операции игрока |

## Важно

- Цены подарков в `catalog.py` примерные. Актуализируйте их под рынок (Fragment, маркетплейсы), иначе кейсы будут убыточны.
- Игра на ценности с возможностью вывода — это азартные игры. Во многих странах (включая РФ) для этого нужна лицензия.
  Также проверьте правила Telegram для Mini Apps и Stars.
